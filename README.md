# PrismPress 棱镜发布台

把一篇 Markdown 整理成适合不同平台的内容，减少重复排版和发布表单整理。

线上体验：[PrismPress](https://prismpress-sigma.vercel.app/)。支持本地配图自动匹配与可选 AI 封面。

## 使用流程

打开网站默认预览“AI 工程五级进阶”，原稿区可切换“智能体核心概念”。已有个人草稿不会自动覆盖示例，点击“继续上次编辑”恢复；查看示例不覆盖保存的草稿。示例标题旁有“示例”标签。

1. 点击“导入文章”，选择 Markdown 文件（可同时选配图）或整个文章文件夹；文件夹会一次读取正文与子目录配图，多篇正文先选择一篇。只有图片时须明确选择为当前文章补图。只读取当前文章引用的图片，忽略无关图片及其他文档；显示处理进度并可取消。也可展开原稿选择两篇真实示例。
2. 随时切换平台，检查富文本、Markdown 或章节摘要图集；展开原稿可边改边预览。
3. 预览后进入“准备发布”，点击“复制正文并打开平台”，在官方编辑器粘贴正文，单独填写标题，检查图片后保存草稿或发布。浏览器拦截新标签页时，可点击“打开平台编辑器”。暂缓安装发布助手；主流程不依赖扩展。

面向微信公众号、知乎、B站、掘金、CSDN、小红书与抖音整理内容。小红书提供图集导出；抖音可选择文章或图集，其他平台提供正文复制。图集是章节摘要，不含全部文字与原图。两篇示例内置预制封面；自定义文章也支持按需使用可选 AI 封面。

## 本地运行

```sh
npm install
npm run dev
```

使用终端显示的本地地址。`npm test` 运行回归测试，`npm run build` 生成静态站点到 `dist/`。首版已部署至 Vercel。

## 数据与依赖

原稿、配图与复制记录保存于当前浏览器；编辑区保留短图片路径，配图单独存入 IndexedDB，预览与复制正文时自动关联图片数据。使用“完整备份”可保存原稿与本地配图；清理浏览器数据会删除草稿。

B站、抖音文章复制会先准备图片数据，再随正文写入剪贴板；远程图片通过站内 `/api/image` 读取，本地图片优先使用保留的数据。其他正文平台的本地配图通过 PrismPress 的 Vercel Blob 公开存储提供地址，普通用户无需配置图床。图片托管接口不接收正文，原图仍留在浏览器；持有公开图片链接的人可访问图片。AI 摘要和封面会发送正文或正文参考，详见下文。应用不读取平台账号、不自动发布。PicList 保留为高级选项。

### 准备正文与配图

- B站与抖音配图最多三张并行处理，按钮显示图片完成数、整理正文、写入剪贴板等阶段。B站保持图片比例；抖音对极窄图片补白，不裁切原图。
- 可以点击“取消等待”；失败或超时会退出等待并保留原稿，已处理的图片可在当前页面重试时复用。不会通过忽略失败图片或降级成纯文字来显示成功。
- 单图读取/处理等待30秒，配图整体90秒，正文准备整体120秒；剪贴板写入等待10秒。浏览器底层剪贴板操作不能撤销，取消或超时会停止后续跳转，但已经发出的写入仍可能晚到。复制时保持页面在前台，并按浏览器提示允许剪贴板访问。

图片检查按地址识别已知风险，不能替代在官方编辑器中逐图确认。内联图片是否接受由目标平台决定。公式由MathJax在浏览器中转换，首次使用需要加载相应资源。

图标许可与来源：`public/icon-studio/LICENSE`、`public/platforms/sources.json`。产品评审与参赛待办：[评审记录](docs/reviews/2026-11-17-competition-product-review.md)。

### 可选 AI 封面

封面仅在点击“生成此比例”或“重新生成此比例”后调用服务。每次一张，不自动重试；切换文章、比例和读取缓存不会调用生图 API。当前正文参考取前 16000 字，生成后在浏览器裁切为目标尺寸，须检查文字和构图。

运营方复制 `.env.example` 为 `.env.local`，填写 `AIARTMIRROR_API_KEY` 和 `AIARTMIRROR_MODEL`。模型默认按当前选择使用 `gpt-image-2.6-flare`；供应商文档目前只明确保证 `gpt-image-2`，实际线路以联通测试为准。参赛演示版不设口令；访客点击即可调用，API 密钥只保存在服务端。

`npm run dev` 同时运行 Vite 和本地 `/api/cover`，读取 `.env.local`（Node 22+）。Vercel 部署时在项目服务端环境变量中配置同名变量；不要使用 `VITE_` 前缀，不要提交本地凭据。函数单次等待 150 秒，不自动重试。站内切换页签后任务继续并保存；停止等待不会取消上游，返回同稿同尺寸会接回原任务。关闭或刷新整页仍可能丢失执行中的结果，且不保证不计费。响应通过二进制 PNG 传输；超过 4 MiB 会明确报错，须核对供应商记录再重试。

生成封面会将标题和正文参考发送至 AIArtMirror。图片按正文内容与比例缓存在当前浏览器 IndexedDB，修改正文后不会误用旧图；清理浏览器数据会删除缓存。

### AI 发布资料提炼与完整备份

- `OPENAI_API_KEY` 为摘要服务独立密钥；未配置时返回服务不可用，绝不复用封面密钥。默认 `OPENAI_BASE_URL=https://api.aicodemirror.ai`、`OPENAI_MODEL=gpt-6.1-sol`。
- 首次进入“准备发布”时自动将标题与全文发送至 aicodemirror.ai，提炼摘要和标签；同稿切换平台复用缓存，可手动重新提炼。保留原文章标题。结果在当前浏览器缓存，当前任务可在站内切页后继续；整页刷新不保证恢复进行中任务。
- 同稿前端复用任务；服务端仅在单函数实例内合并并发同稿。现有 Vercel 项目为 `/api/passport` POST 配置每 IP 每 60 秒 6 次的边缘限频（不设置总消费预算）。新部署项目必须单独配置同类边缘规则；本地服务没有跨实例限频，限频也不保证消除分布式滥用。
- 提炼结果用于发布资料、图集标题/配套文案和新封面提示；不改写原稿。AI 结果更新使原复制记录失效。
- “完整备份”导出 ZIP：原稿、改好本地图片路径的可迁移稿、当前引用的本地原图，以及当前标题和正文已缓存的生成封面。远程图片保留链接，不会被自动下载；解压后将可迁移稿与 assets 目录一起导入即可恢复本地配图。

### 站内图片托管

运营方将公开 Vercel Blob 存储连接到项目，配置服务端 `BLOB_READ_WRITE_TOKEN`。普通用户无需口令、图床或开发者密钥。支持 PNG/JPEG/GIF/WebP，每张最多 3MB；失败会停止复制并保留原图。上传按图片内容去重，同一浏览器草稿会保存远程地址。当前演示版没有账户与独立配额体系。公开图片不会因清理浏览器而从服务器删除。

验证记录（2026-11-23）：167项自动测试、类型检查及生产构建通过。开发者本人反馈已逐个平台体验，暂未发现问题，并确认部署；这项反馈不代表所有账号、文章和格式都已覆盖。此前独立测试包括知乎、掘金、CSDN两图文章保存重开，以及抖音两图、九图文章保存重开。B站外链图片失败已复现，现改为图片数据复制；本次助手确认七图数据已写入剪贴板，后续平台接收以开发者本人的体验反馈为依据。B站此前存在部分表情保存被替换的问题；小红书长文过滤图片与粗体，所以网站只提供图集入口。目标平台可能清理字体、颜色等样式，不能保证像素级一致，发布前仍需检查。

摘要按全文主旨、关键方法和结论生成，排除来源标题、作者、日期和目录。公众号不超过120字、掘金建议50～100字（编辑器上限100）、CSDN不超过256字、抖音文章不超过30字；抖音单独改写，不截断公众号摘要。知乎、B站、小红书长文不显示独立摘要字段。摘要和标签直接展示，不再显示“其他平台”或复制记录。
