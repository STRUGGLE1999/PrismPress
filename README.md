# PrismPress 棱镜发布台

把一篇 Markdown 整理成适合不同平台的内容，减少重复排版和发布表单整理。

## 使用流程

1. 准备文章：导入 `.md` 文件与配图，或选择两篇真实博客示例。
2. 选择平台：检查富文本、Markdown 或章节摘要图集；需要时返回原稿修改。
3. 准备发布：复制正文与发布资料，下载可用的封面，再打开官方编辑器粘贴、检查和发布。

支持微信公众号、知乎、B站、掘金、CSDN、小红书与抖音。图集是章节摘要，不含全部文字与原图。两篇示例有独立制作的封面；自定义文章不调用运行时生图服务。

## 本地运行

```sh
npm install
npm run dev
```

使用终端显示的本地地址。`npm test` 运行回归测试，`npm run build` 生成静态站点到 `dist/`。当前仓库内未记录公开部署地址。

## 数据与依赖

原稿与复制记录保存于当前浏览器；下载原稿可作为备份。清理浏览器数据会删除草稿。远程图片请求原图床；主动上传素材时才请求本机 PicList Server。应用不托管稿件，不读取平台账号，不自动发布或确认发布结果。

图片检查按地址识别已知风险，不能替代在官方编辑器中逐图确认。内联图片是否接受由目标平台决定。公式由MathJax在浏览器中转换，首次使用需要加载相应资源。

图标许可与来源：`public/icon-studio/LICENSE`、`public/platforms/sources.json`。产品评审与参赛待办：[评审记录](docs/reviews/2026-11-17-competition-product-review.md)。
