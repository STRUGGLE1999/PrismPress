# PrismPress 发布助手 0.4（本地试用）

> 此助手为暂缓的实验代码，不属于当前参赛网站体验。网站现使用复制/导出后由用户在平台检查发布，无需安装扩展。

## 日常流程

PrismPress 选择支持的平台 → **发送到草稿** → 助手填入 → 用户检查、保存并重开核对，最后自行发布。日常无需交接文件。

当前支持小红书长文、抖音文章、知乎、CSDN富文本编辑器、掘金Markdown编辑器、B站专栏。公众号保留复制入口，本轮其页面被浏览器站点安全策略拦截，未增加公众号自动操作权限。

首次通过Chrome扩展管理页加载本目录；已安装旧版的用户需重新加载并确认新增的平台访问权限，然后刷新PrismPress。尚未上架商店。需登录目标平台；助手优先复用检查为空白的编辑器，否则打开固定平台入口。CSDN当前需使用富文本编辑器，尚未适配其Markdown模式。

**填入与保存分开反馈**：网站只报告“已填入，待保存/待确认保存”，不点击保存或发布。抖音发现上次未发布文章时停止，请先处理原稿，或自行在平台新建空白文章后再发送。已有标题、正文或图片的页面拒绝写入。失败保留部分内容，不自动重试；再发前先检查目标页，避免重复稿。

## 平台适配与边界

- 小红书：沿用原生插图按钮，每张只插入一次，检查全文、图片数量、加载及位置。
- 抖音：富文本粘贴，表格转逐行文本，超链接保留文字；平台出现不支持格式提示时停止。
- 知乎：正文分段填入，图片交给原生上传输入；链接保留展示文字，避免自动卡片改写正文。加载阶段区分图片上传失败占位图与真实图片，延迟加载图会主动请求加载。
- CSDN：通过同源框架填入富文本。拖拽图标、编辑控件不算正文图片；超链接保留展示文字，避免平台卡片替换链接文案。CSDN保存时会替换标题中的部分补充平面字符（例如本次恐龙表情），发送前明确拒绝此类标题；本轮正文中的这些字符保存后仍保留。
- 掘金：先通过原生图片粘贴获得平台URL，再填写Markdown。预览全文及图片位置必须与文章一致，原始代码块和链接不靠字符串截取改写。当前不支持无法与预览图片一一对应的图片引用写法，会明确停止。
- B站：编辑器先接收内嵌图片，平台保存草稿时转存为平台地址；“已填入”不代表已转存。已验证保存并从草稿箱重开后两图均为平台地址。保存时部分补充平面字符会变为问号，因此含此类字符的标题或正文在发送前明确拒绝，避免静默损坏；不会代替用户删除字符。

当前拒绝公式SVG/Math、音视频。最多100图、每图4MB、包总计48MB，是助手校验限制，不是平台发布上限。所有账号、文章结构、大批量图片、手机展示、慢网中断和关闭页面恢复均未全面验证。

## 权限与数据

- 来源只允许正式站 `https://prismpress-sigma.vercel.app` 与本机 `http://127.0.0.1:5175`、`http://localhost:5175`。后台再次核对来源和顶层页面；拒绝其他来源、端口、子框架和任意目标URL。
- host权限仅六个平台的创作域名。MV3后台接收文章和图片并操作编辑器；不申请全站、Cookie、密码或剪贴板权限，不调用平台私有上传接口。
- 内容在网站、本机助手和用户选定的平台间传递；助手不把文章上传到PrismPress服务端，不把正文写入扩展存储。读取原始远程图片可能使用网站已有图片代理。
- 同平台一次只运行一个任务；HTML使用允许列表。刷新网站、重载扩展或关闭页面可能失去结果回传，需检查目标页后再决定是否重发。
- 网站对小红书/抖音继续兼容0.3助手；其余四个平台需要0.4。popup文件导入仅为小红书调试/恢复备用。

## 已有验证

0.2：小红书当前Chrome/账号、公开示例全文7图、手动保存及重开。

0.3：一篇两图文章在小红书/抖音网站直连、结果回传、手动保存及重开。

0.4：同一两图文章在知乎、掘金完成网站直连和草稿重开；CSDN使用仅调整标题的测试副本，B站使用去除三处补充平面字符的测试副本，两者均完成网站直连、手动保存及同稿重开，全文、两图数量和位置一致。测试副本的改动仅用于兼容性验证，原博客文件未修改；网站原测试文章已恢复。字符损坏提示在发送前触发，未使用“已填入”冒充“已保存”。

以上仅为当前浏览器、账号及样例的证据，不是所有文章的可靠性保证。未正式发布，0.4网站功能仍仅在本地，未部署线上。
