# 封面与图集的独立运行

网站的视觉能力由项目源码和服务端 API 提供，不需要用户安装 Codex 或本地技能。

- `shared/visual-design.mjs`：三种视觉规范和图片提示词，封面与插图共用；风格版本参与缓存身份。
- `src/core/platforms/deck/core.ts`：按原稿选取核心主题和完整短句，不读取文章图片；自动最多八页，短内容不补页。当前为规则摘录，不是大模型重写。小红书/抖音使用选定的清爽漫画模板，图标与气泡由源码直接绘制。
- `src/core/platforms/deck/render.ts`：清爽漫画基础上的杂志专栏、手账便签、醒目图解排版；按内容使用图文、要点、步骤或对比布局。复杂公式、表格与超量编辑回退到保真分页。
- `src/components/deckExport.ts`：预览与 PNG 共用 SVG，顺序打包图片和配套文案。原图加载失败会阻止导出，不以空白代替。
- `api/cover.mjs`：主动点击后调用图片供应商；图集不提供插图生成或替换入口，内容按固定版式组织。打开页面和切换风格不生成付费图片。
- `api/image.mjs`：公开 HTTPS 位图的读取中转，限制地址、DNS、重定向、体积与时间；不提供私人资源访问能力。

设计方法参考 JimLiu/baoyu-skills 的 baoyu-image-cards（内容拆分、流程/对比、系列一致性）以及本地 handdrawn-knowledge-cards（便签、短句、重点引导）。这些方法被转成项目自有模板；没有复制或依赖技能执行脚本，也没有把技能整套生图工作流移入网站。字体采用设备系统回退，跨设备字形可能不同。

图集页内编辑在当前工作区使用，导出用于保存成品；原稿、原图和缓存的备份仍由完整备份功能负责。原始全文不因图集精选而被修改。原文分页仍保留为内部编译兼容代码，不向产品界面提供选择。图片可下载不等于已经上传平台或保存草稿。

## 紫韵简报（2026-11-20 新增）

由用户提供的七张图提炼：浅紫纸底#F6F2FD、近黑紫标题、白色圆角卡片、紫色重点、少量暖黄、封面淡圆几何装饰。它是两图文平台独立新增模板，不替换漫画三风格；封面生图选择器不展示本模板。只使用视觉规律，不复制参考新闻、署名、水印或账号；不读取参考图片作为运行时素材，不调用生图API。

封面使用大标题/黄色短线/主题卡，正文使用白卡与浅紫强调卡；短前缀来自原文冒号标签，不自行编写事实或统计。预览与PNG共用SVG，分页同时测量漫画与简报容量。保留1080×1440标准输出，不逐张复刻参考中的长图高度。
