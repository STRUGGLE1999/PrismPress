# PrismPress 图标

24 枚产品图标：1 枚原创棱镜标识，以及 23 枚用于本站的 Kubai 范例图标。保留上游版权声明与 LICENSE；范例图标作为 PrismPress 产品资源使用。

在网站运行时打开 `/icon-studio/`，可查看动态效果与七种色板。网站与静态 SVG 默认使用「彩色」色板，以紫色、珊瑚红、青瓷与薄荷绿区分功能。静态文件在 `/icons/`。

## 维护

`src/engine.js` 是未经修改的上游引擎。`src/bridge.js` 连接 React 组件，组件卸载时清理动画与事件，并复用实例编号。图标 SVG 由引擎管理，React 只管理容器。

```sh
node public/icon-studio/scripts/check.mjs --out output/icons
node public/icon-studio/scripts/check.mjs --accent '#F59E0B' --out output/icons-light
node public/icon-studio/scripts/export.mjs --out public/icons
```

系统“减少动态效果”在页面载入时生效。静态导出为独立 SVG，不需要加载引擎。
